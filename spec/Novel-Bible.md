## 2. 世界观设定

### 2.1 宇宙观总纲

在时间和空间诞生之前，存在一个被称为 **"源"** 的初始意识。源创造了 **"万界体系"**——一个由无数独立世界组成的宇宙网络。每个世界都是源对"文明可能性"的一次实验：它设定不同的物理法则、魔法规则、生命形态，然后观察文明如何演化。

源创造完万界后便陷入沉睡（或死亡？或消失？——这是本作最大谜题）。源的躯体化作 **"归墟"**（莲心），源的力量碎片散落于万界之中，化作每个世界的核心规则。

然而，在源沉睡之后，**"祂们"** 出现了——一群在源之后诞生的高等存在，发现了万界体系这个"被遗弃的实验场"。祂们开始对这个体系进行干预和改造……

### 2.3 诸天无限流：穿越机制

**核心规则 — "锚定者协议"**：

1. **锚点唯一**：主角林朔的灵魂被绑定于归墟之心（一颗名为"墟核"的水晶），成为唯一合法的"锚定者"。只要墟核不灭，林朔不死。
2. **位面适配原则**：进入每个子世界时，林朔和玩家必须适应该世界的规则——
   - 武侠世界：魔法、科技失效，只能使用内力/招式
   - 修仙世界：科技武器降级为凡铁，必须按该世界的修炼体系成长
   - 科幻世界：魔法失效，只能使用科技武器和基因强化
   - 系统会自动将穿越者的能力"翻译"为该世界允许的等价物
3. **穿越消耗**：每次穿越需消耗"源能"（从归墟核心产出 + 完成任务获取）。低级世界消耗低，高级世界消耗极高。
4. **任务系统**：每个子世界都有一个或多个"源界碎片"（源的力量碎片）。回收碎片 = 完成该世界主线任务。
5. **世界不重置**：不同于传统无限流，子世界是**真实存在的文明**，穿越者离开后世界仍在运转。玩家的行为会产生永久性后果。
6. **回归锚定**：林朔可以随时回归归墟，玩家则需要通过"传送门"（需林朔开启）才能回归。

### 2.4 第四天灾：玩家体系

**玩家来源**：地球。林朔被选中后，系统自动在地球发布了一款名为《万界》的全息VR游戏。"玩家"们以为自己通过VR设备进入游戏，实则灵魂被投射到真实的万界之中。

**玩家特权（为什么是"天灾"）**：
- **不死**：在子世界死亡 → 灵魂回归归墟 → 冷却后可再次穿越（消耗源能）
- **成长加速**：玩家的经验获取速度是原住民的 3-5 倍
- **面板可见**：玩家能看到数据化面板（属性/技能/任务），原住民看不到
- **语言通晓**：自动翻译所有语言

**玩家限制**：
- **不真正理解**：玩家以为一切都是NPC和代码，不知道这些是真实世界。这是系统刻意维持的认知屏障。
- **源能绑定**：玩家的穿越次数和复活次数受限于林朔分配的源能额度
- **行为不可控**：玩家会做出任何事——有人认真做任务，有人建公会经商，有人屠杀NPC取乐……林朔不可能完全控制

**弹幕/群聊机制**：林朔可以看到玩家在归墟广场的聊天（类似弹幕），这是他了解前线情况的重要信息来源，也是喜剧元素的重要来源。

### 2.5 千层饼剧情：归墟的六层揭秘

归墟（莲心）不仅是空间枢纽，更是时间与历史的叠加体。每次主角回归归墟，都能多揭开一层真相。

| 层数 | 揭示内容 | 对应剧情阶段 | 反转力度 |
|------|---------|-------------|---------|
| **第一层：废墟** | 归墟是一座巨大的远古文明遗迹，看起来像失落的神殿。主角以为这只是主神空间的花哨外皮。 | 第1-30章 | ★ 基础设定 |
| **第二层：前哨站** | 归墟不是神殿，而是"源界文明"的星图观测站。源界曾是横跨万界的超级文明，因未知原因陨落。碎片散落于各子世界。 | 第31-80章 | ★★ 世界观扩容 |
| **第三层：实验场** | 源界不是自然演化的文明——它是"源"刻意创造的。万界体系也不是宇宙的自然形态，而是源设计的"文明可能性沙盘"。 | 第81-150章 | ★★★ 认知颠覆 |
| **第四层：入侵者** | 源沉睡后，"祂们"发现了万界体系并开始渗透。祂们就是千层饼反转中的"高层存在"。主角发现自己一直在和祂们的代理人对抗。 | 第151-250章 | ★★★★ 敌人浮现 |
| **第五层：循环者** | 林朔不是第一个锚定者。在漫长的历史中，已有无数锚定者被选中、被消耗、被抹除。每一次轮回都以锚定者的失败和归墟的"重置"告终。林朔可能是第N次循环。 | 第251-350章 | ★★★★★ 存在危机 |
| **第六层：我是谁** | 林朔发现自己的记忆是被植入的——"林朔，28岁，前游戏策划"是一段精心设计的背景故事。他的真实身份与源有着直接关联（可能是源的碎片意识转世/源的"继承者"预设体/或与"祂们"有关）。这层真相将是终局的最大反转。 | 第351-500章 | ★★★★★★ 终局炸弹 |

## 3. 角色系统

### 3.1 主角档案：林朔

| 维度 | 内容 |
|------|------|
| **姓名** | 林朔 |
| **年龄/外貌** | 28岁（自称），实际年龄未知（千层饼第五层暗示他可能经历了多次循环）。外貌：清瘦，戴眼镜（习惯性动作是推眼镜），眼神冷静到近乎冷漠，但偶尔露出疲惫和茫然。 |
| **性格核心（3关键词）** | **理性控制欲**（必须理解规则才能行动）、**道德骑墙**（在"保护玩家"和"利用玩家"之间摇摆）、**孤独感**（唯一知道真相的人） |
| **初始状态** | 普通游戏策划，被系统强行绑定成为锚定者，对万界一无所知，只想找到回家的路 |
| **中期状态** | 适应锚定者角色，成为玩家群体的"幕后BOSS"；开始怀疑自己的身份和系统的真实目的 |
| **终局状态** | 揭开所有真相，做出终极选择：是维持万界体系（成为新的"源"），还是打破这个实验场（解放所有世界） |
| **核心欲望** | 知道自己到底是谁，找到真正的自由 |
| **核心恐惧** | 发现自己的一切——记忆、身份、选择——都是被设计的，"自由意志"只是幻觉 |
| **习惯动作/口癖** | 推眼镜（思考时）；"有意思"（遇到出乎意料的情况）；记录一切（随身携带一个能量凝结的记事本） |
| **说话方式** | 简短、直接、极少废话。对玩家说话时公事公办，偶尔毒舌。独处时自言自语（流露真实情绪） |
| **能力弧线** | 初期：系统操作员（分配任务/管理源能/开门）→ 中期：在多个世界积累战斗经验和知识 → 后期：觉醒自身隐藏的力量（与真实身份相关） |

**Lajos Egri 三维分析**：
- **生理**：28岁男性，体质一般（初始），长期面对屏幕导致轻微颈椎问题。后期通过多个世界的训练逐渐强化。
- **社会**：前游戏策划，职场中层，父母离异（记忆中的设定，真实性存疑），社交圈窄。被系统选中后彻底脱离地球社会。
- **心理**：控制欲源于对不确定性的恐惧；道德挣扎源于他本质上不是冷血的人，但处境逼迫他做出冷血决策；孤独感是最核心的心理驱动力——他是万界中唯一"清醒"的人。

## 4. 冲突架构

### 4.1 核心冲突线（贯穿全篇）

**林朔 vs "系统/命运"**：林朔想弄清自己的真实身份，找到一个不被他者设计的自由选择。但每一步接近真相，都让他发现更多自己被操纵的痕迹。最终冲突是：接受被设计的命运（成为新的"源"），还是摧毁这个实验场（代价是无法估量的文明毁灭）。

### 4.2 次要冲突线

| 冲突线 | 涉及角色 | 性质 | 展开阶段 |
|--------|---------|------|---------|
| **玩家 vs 原住民** | 玩家群体 vs 各世界NPC | 文化冲突/道德困境 | 全程 |
| **林朔 vs 白夜** | 林朔、白夜 | 理念对抗（接受 vs 反抗） | 中期爆发 |
| **万界 vs "祂们"** | 全体 vs 高等存在 | 生存战争 | 后期主线 |
| **叶琳 vs 魔剑** | 叶琳（武侠世界） | 人性试炼 | 第一花瓣世界 |
| **唐川 vs "真相"** | 唐川（当知道这不是游戏） | 存在危机 | 中期转折点 |

## 5. 幕结构（三幕式 + Save the Cat! 15节拍）

### 第一卷：归墟苏醒（约1-80章，40万字）

| 节拍 | 章节范围 | 核心内容 |
|------|---------|---------|
| **开篇画面** | 第1-3章 | 林朔在工作时被系统强行绑定，天旋地转后发现自己站在一座巨大的废墟中央（归墟）。墟核第一次对他"说话"。 |
| **主题陈述** | 第4-5章 | 林朔试图逃跑/关机，发现完全无法摆脱。墟核告知他"锚定者协议"的内容。林朔第一次崩溃和接受。 |
| **激励事件** | 第6-10章 | 第一批玩家被系统自动投放到第一个花瓣世界（武侠·苍云之殇）。墟核警告：如果不管理玩家，源能消耗过快会导致归墟崩塌，所有人都会死。林朔被迫开始工作。 |
| **争论** | 第11-15章 | 林朔试图用"GM指令"控制玩家行为，彻底失败。玩家开始胡作非为——有人想攻略女NPC、有人想推翻朝廷、有人在少林寺门口摆摊卖烤串…… |
| **第一转折点** | 第16-20章 | 林朔发现玩家中有一个"账号不存在"的神秘玩家（伏笔V3）。同时，武侠世界的魔剑（碎片具象化）开始影响原住民。林朔意识到这不是游戏——这是真实的。他必须亲自下场。 |
| **B故事** | 第21-30章 | 林朔以"神秘NPC"身份进入武侠世界，遇到叶琳。同时通过唐川开始建立与玩家群体的联系。这段是读者和主角一起"认识这个世界是真实的"的过程。 |
| **娱乐游戏** | 第31-45章 | 林朔开始认真运营：建立公会体系、分配任务、制定规则。玩家们逐渐形成组织。叶琳的苍云派命运开始与玩家的行动挂钩。喜剧+战斗的混合节奏。 |
| **中点** | 第46-50章 | 林朔成功回收第一个源界碎片（魔剑的核心），武侠世界恢复平衡。但回收碎片时，他看到了碎片的"记忆闪回"——源界文明毁灭的零碎画面。归墟也因此解锁了新区域，揭示了第二层真相：归墟是源界的星图观测站。同时，第一个"祂们"的代理人出现。 |
| **坏人逼近** | 第51-65章 | 代理人开始干扰玩家行动，在第二个花瓣世界（末日废土）制造混乱。林朔发现代理人能直接影响墟核——系统开始不稳定。玩家中出现"故意搞破坏"的群体。 |
| **一切失去** | 第66-70章 | 废土世界的回收行动失败。叶琳主动提出参加废土世界行动，却被代理人重伤。林朔第一次失去一个他在意的人（叶琳濒死）。墟核因源能不足开始闪烁。 |
| **暗夜灵魂** | 第71-75章 | 林朔独自坐在归墟中，看着墟核闪烁。他开始质疑一切——如果这些世界注定要被"祂们"吞噬，回收碎片还有什么意义？白夜第一次以残影形式出现。 |
| **第二转折点** | 第76-80章 | 林朔从白夜的残影处得到一个关键信息："你在归墟看到的壁画有答案。"林朔发现壁画底层的隐藏铭文——"第47次循环"。同时，墟核恢复，第二层花瓣（觉醒界）解锁。第一卷结束。 |

### 第二卷：花瓣展开（约81-250章，85万字）

| 节拍 | 核心内容 |
|------|---------|
| **觉醒界探索** | 进入修仙世界和星际世界。每个世界揭示更多源的真相。白夜正式登场，成为林朔的（不情愿的）向导。 |
| **代理人战争** | "祂们"派出的代理人在各个世界与林朔的玩家对抗。林朔发现自己面对的并非一个统一敌人，而是多个"祂"的不同代理人——祂们之间也在内斗。 |
| **真相第3-4层** | 揭示万界是"实验场"、揭示"祂们"的存在。 |
| **唐川的觉醒** | 唐川偶然发现了真相——这不是游戏。他的世界观崩塌，但也由此成为林朔最坚定的盟友。 |
| **终局战场预演** | 在某个觉醒界爆发第一次大规模战役——玩家+原住民 vs 代理人军队。 |

### 第三卷：归墟终局（约251-500章，125万字）

| 节拍 | 核心内容 |
|------|---------|
| **第5层真相** | 揭示循环——林朔不是第一个锚定者，白夜是上一轮的幸存者。每一轮锚定者都失败了，归墟都重置了。 |
| **代理人的真实身份** | 揭示"祂们"的代理人中，有些是前几轮循环的玩家——他们被"祂们"收编/腐化/改造了。 |
| **第6层真相** | 林朔的真实身份——可能的选择：他体内有源的碎片意识 / 他是源为"突破循环"而设计的特殊锚定者 / 他本身就来自于"祂们"的阵营但被源策反 |
| **终极选择** | 维持万界体系 vs 摧毁实验场 vs 成为新的"源"重建规则 |
| **终局大战** | 玩家+各世界联军 vs "祂们" |
| **尾声** | 开放结局，留白 |
