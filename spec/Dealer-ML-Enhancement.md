# 发牌员 ML 增强集成设计 Spec

> 本文档定义发牌员（`VoiceEngine._deal` / `_deal_chaos`）的 ML 增强方案。
> 配套文档：
> - `REDESIGN-Overview.md`：重构总纲（抗罐头原则）
> - `WordCount-Driver.md`：字数目标驱动循环
> - `Config-Schema.md`：配置项 schema（本文档第 6 节扩展它）
>
> 现状基线：`_deal` 已实现 **7-bag 无放回 + 跨包接缝防涝**（commit `78df347`）。
> 本 Spec 在其之上叠加两层增强，**不替换、不破坏**既有正确性骨架。

---

## 1. 目标与边界

### 1.1 要解决的剩余弱点
7-bag 已解决「精确重复 + 旱涝分布」，但有两个它压不住的弱点：

| 弱点 | 表现 | 7-bag 能否解决 | 由谁解决 |
|---|---|---|---|
| 邻接自然度 | 片段间无转移关系，均匀发牌导致组合偏机械 | 否（均匀 bag） | 马尔可夫转移层 |
| 语义近似重复跨包漏网 | 同义改写句跨包撞车，精确 bag 挡不住 | 否（只挡精确） | 嵌入近重去重层 |

### 1.2 不可破坏的四项优势（硬约束）
1. **确定性**：同 `--seed` 同输出。
2. **零依赖**：不引入重型运行时（除非用户批准嵌入去重依赖）。
3. **可复现**：不依赖外部网络/服务。
4. **快**：离线 20 万字总耗时须保持秒级。

### 1.3 不做的事
- **不**用 LLM 整体重写生成器（会摧毁上述四项优势，也失去「设计即抗罐头」的控制力）。
- **不**引入 GPU 训练流程。DNN 仅作「推理期过滤器/打分器」。

## 2. 总体架构（三层）

```
                 ┌──────────────────────────────────────────────┐
   候选碎片 ────▶ │ Layer 3: 嵌入近重去重 (DNN, 可开关)            │
                 │   · 近期已发片段向量索引 (语义记忆)            │
                 │   · 拒绝与近期 near-duplicate 的候选           │
                 └───────────────────────┬──────────────────────┘
                                         ▼
                 ┌──────────────────────────────────────────────┐
   上一张碎片 ──▶ │ Layer 2: 马尔可夫转移感知采样 (order-1/2)      │
                 │   · P(next|context) 加权 + order 回退 + 平滑   │
                 └───────────────────────┬──────────────────────┘
                                         ▼
                 ┌──────────────────────────────────────────────┐
   队列(queue_key)▶│ Layer 1: 7-bag 无放回 + 跨包接缝防涝 (已做)   │
                 │   · 包内零重复 · 跨包不紧邻重复 · 确定性       │
                 └───────────────────────┬──────────────────────┘
                                         ▼
                                    发出的碎片
```

- **Layer 1 永远在线**（正确性骨干，来自 `78df347`）。
- **Layer 2 / Layer 3 为增强层**，各自可独立开关（配置 / 构造参数）。
- 三层串联：候选先过 Layer1（去精确重复 + 防涝），再过 Layer2（转移加权），最后过 Layer3（语义去重）。任何增强层关闭 → 干净退化为下一层行为，**保证零回归**。

---

## 3. Layer 1（已有，不变）

- 实现：`VoiceEngine._deal` + `_refill` + `_deal_last`，按 `queue_key` 独立牌包。
- 保证：包内零重复、跨包不紧邻重复、确定性（seed 派生 `_deal_rng`）。
- 本 Spec 不修改 Layer 1 逻辑，仅在其输出/入口处串联 Layer 2/3。

---

## 4. Layer 2：马尔可夫转移感知发牌

把「均匀无放回」升级为「转移感知无放回」——发牌不再均匀 pop，而是按
`P(next | 上一张)` 加权采样，提升邻接自然度。

### 4.1 转移数据来源（关键决策，三选一）

| 方案 | 描述 | 优点 | 缺点 |
|---|---|---|---|
| **(A) 自举语料** | 首跑用均匀 bag 生成 → 把成稿按 queue_key 切片统计 `(last→next)` 共现 → 持久化 `deal_transitions.json` | 零手工、自动学本项目语感 | 跨 run 才稳；首跑退化为均匀；语料质量依赖生成本身 |
| **(B) 词库共现提示** | 在 `word_bank` 给每碎片加 `follows` 提示（如「视觉碎片X 常接 听觉碎片Y」） | 可控、确定、无需语料 | 标注成本高、覆盖不全 |
| **(C) 混合（推荐默认）** | 优先 (B)，缺失回退 (A) 学到的统计 | 兼顾可控与自动化 | 实现稍复杂 |

> **MVP 建议**：先实现 (A) 自举 + 回退均匀，把整条 pipeline（统计→持久化→加载→加权采样→回退）跑通验证；随后再补 (B) 手工提示作为精修。

### 4.2 采样算法

```
维护 self._transitions[queue_key]: { context_tuple -> Counter(next) }
context_tuple 长度 = order（order=1 → (last,)，order=2 → (last, current)）

每发一张：
  1. 取当前包候选集 C（Layer1 已保证 C 内不重复）
  2. 若 Markov 启用且 context 命中统计：
       权重 w(x) = (count(context, x) + α) / (total(context) + α*V)   # Laplace 平滑
       按 w 加权从 C 中采样
  3. order 回退：order-2 的 context 未见 → 用 order-1 的 context；
                 order-1 也未见 → 退化为均匀（C 内均匀 pop）
  4. 与 Layer1 接缝防涝兼容：加权后仍强制 next != last
     （复用 _deal_last 避让，见 _refill）
```

- **order 甜区**：碎片池 3–20 条，order-1/2 最佳（搜索结论：order 越高越像抄原文，order≥5 基本复述）。**默认 order=2**。
- **Laplace 平滑 α**：默认 `0.5`，避免零频死路（生成中断）。
- **稀疏处理**：小池转移极稀疏，回退链保证永不抛异常、永不死锁。

### 4.3 确定性

- 转移矩阵一旦持久化即固定；采样用 `self._deal_rng`（seed 派生）→ 同 seed 同输出。
- 自举语料本身由 seed 决定 → 整条复现链完整（首跑 seed 固定 → 转移文件固定 → 后续 run 固定）。

## 5. Layer 3：嵌入近重去重（DNN）

引轻量句向量模型，跨包维护「语义记忆」，拒掉**近似**重复——补精确 bag 的盲区。

### 5.1 模型选型

- **默认**：`sentence-transformers/paraphrase-multilingual-MiniLM-L6-v2`
  （多语、含中文、~90MB、纯本地推理；即 DCE 论文用的 all-MiniLM-L6-v2 多语版）。
- **轻量替代（零依赖）**：局部敏感哈希（SimHash）对碎片做语义哈希近似去重，
  精度低但零模型依赖——作为「不装重依赖」时的降级选项。
- 新增依赖：`sentence-transformers`（或 `optimum` + `onnxruntime` 量化版降体积）。
  **这是项目首个重依赖，须用户批准**（见 §8）。
- 离线、无网络调用；可批处理 embedding 降低开销。

### 5.2 语义记忆与拒发

```
每个 queue_key 维护近期窗口 W（默认最近 24 张）的 (向量, 文本)
候选 x 发出前：
  for y in W:
      if cosine(embed(x), embed(y)) > τ:    # τ 默认 0.82
          拒发 x，改抽下一张（仍走 Layer1/2）
拒发耗尽候选 → 放宽 τ 或放行（保证不卡死）
```

- **τ 与窗口可配置**：τ 过高→漏检，过低→误伤正常复用。默认 τ=0.82、窗口=24。
- 与 Layer1 关系：Layer1 挡*精确*重复，Layer3 挡*近似*重复，二者互补、不冲突。
- 跨队列隔离：每个 `queue_key` 独立记忆，避免不同语义池互相误伤。

### 5.3 性能

- 碎片短（一句），单次 embedding ms 级；20 万字约数千次发牌，总开销秒级
  （批处理可降到亚秒）。**非瓶颈**。
- 模型懒加载（首次发牌时），一次性开销不计入每章。

## 6. 配置与开关（扩展 `Config-Schema.md`）

```json
{
  "dealer": {
    "markov": {
      "enabled": true,
      "order": 2,
      "alpha": 0.5,
      "source": "bootstrap"
    },
    "embedding_dedup": {
      "enabled": false,
      "model": "paraphrase-multilingual-MiniLM-L6-v2",
      "threshold": 0.82,
      "window": 24
    }
  }
}
```

- 默认：Markov 开（若已有转移数据）/ Embedding 关（须先装依赖）。
- **任何层关闭 → 干净退化为现有 7-bag 行为**，零回归。
- `main.py` / `UnifiedNovelEngine` 构造参数透传 `dealer_config`。

## 7. 验证计划（可验证证据）

契合项目「真结构改动 + 可验证」要求，每层配单测 + 端到端对比：

- **`test_deal_markov_transition`**：注入已知转移矩阵（如 `P(b|a)=0.9`），
  200 次抽样断言 >70% 落高权候选；稀疏 context 下 order 回退/平滑不抛异常。
- **`test_deal_embedding_dedup`**：构造两条近义句（如
  `煤烟呛得人睁不开眼` / `烟尘熏得人难以睁目`），断言第二张被拒、改发第三张；
  精确不同的句不受影响。
- **回归**：现有 `test_deal_*` 全绿（增强层关闭时行为不变）。
- **端到端**：`python main.py --target-chars 20000` 跑前后对比——
  人工抽检邻接自然度提升 + 同义改写句跨包出现次数下降（可脚本统计近义对）。

## 10. 风险与缓解

| 风险 | 缓解 |
|---|---|
| Markov 小池转移稀疏导致塌缩 | order 回退 + Laplace 平滑 + 退化为均匀兜底 |
| 嵌入去重 τ 误伤正常复用 | τ/窗口可配；拒发耗尽候选则放行 |
| 重依赖破坏「零依赖」优势 | 默认关；SimHash 降级选项；懒加载 |
| 引入后破坏确定性 | 转移矩阵持久化固定；采样复用 seed 派生 RNG |
| 与既有接缝防涝冲突 | Layer2 加权后仍强制 `next != last`（复用 `_deal_last`） |
