## 二、引擎1：ASP模板引擎强化

### 2.1 原文特征复盘

《宇宙巨校闪级生》的特征（已实现的用 ✓ 标注）：
- ✓ 111部×10卷×7章 嵌套循环
- ✓ 半随机名字生成（姓氏池+名字字池）
- ✓ 24身体部位外貌描写
- ✓ 前缀+类型+后缀装备命名
- ✗ **战斗过程描写太过模板化**（仅"A使出XX → B躲过 → A再使XX"循环）
- ✗ **角色缺乏独特性格标签**（24部位描写可区分外貌，但不区分性格）
- ✗ **对话模板极度有限**（基本只有"你很强/你也不弱"回合制）

### 2.2 强化方案

#### A. 性格标签系统（新增 800+ 条性格维度）

为每个角色在24部位外貌基础上，增加**性格标签随机分配**：

```json
{
  "性格标签": ["冷酷", "热血", "阴鸷", "豪迈", "狡黠", "偏执", "慵懒",
               "急躁", "沉稳", "疯癫", "温柔", "狂傲", "怯懦", "坚毅"],
  "对话风格": {
    "冷酷": ["……", "废话", "滚", "你自找的"],
    "热血": ["来吧！", "我还能战！", "这才像话！", "不够！"],
    "阴鸷": ["呵呵", "你猜", "小心了", "这才刚刚开始"]
  },
  "战斗偏好": {
    "冷酷": {"开局": "沉默凝视→暴起出手", "台词": "<10字"},
    "热血": {"开局": "高声挑战→正面冲锋", "台词": ">20字且带感叹号"}
  }
}
```

#### B. 战斗模板多样化（从3种 → 15种）

当前仅有「A使B避A再使」一种模式。新增：
1. **环境互动型**：利用地形（碎石/断柱/水面）
2. **心理博弈型**：假装露出破绽→反制
3. **兵器克制型**：长短兵器相克的战术描写
4. **流派对抗型**：刚猛 vs 柔韧 / 快攻 vs 防守反击
5. **对话打断型**：战斗中穿插挑衅/嘲讽打断对方节奏

#### C. 词库扩充（新增6个主题词库）

| 新词库 | 条目数 | 用途 |
|-------|:-----:|------|
| `wuxia_terms.json` | ~200 | 武侠世界的招式/内功/门派/江湖术语 |
| `scifi_terms.json` | ~150 | 星际殖民世界的科技/飞船/基因强化术语 |
| `cyberpunk_terms.json` | ~120 | 赛博都市的义体/黑客/企业术语 |
| `cthulhu_terms.json` | ~100 | 克苏鲁深渊的不可名状/疯狂/触手术语 |
| `post_apocalyptic_terms.json` | ~100 | 末日废土的辐射/变异/资源术语 |
| `cultivation_terms.json` | ~200 | 东方修仙的丹药/功法/境界/天劫术语 |

## 三、引擎2：因果链引擎强化

### 3.1 Novel Bible 市场定位校准

根据市场调研，《万界归墟》的标签组合在当前市场中处于**高价值蓝海**：

| 对标作品 | 类型组合 | 成绩 | 万界归墟差异 |
|---------|---------|------|------------|
| 《超神机械师》516w | NPC+第四天灾+星际科幻 | 起点神作 | 我们有**千层饼反转**+**多重世界穿越** |
| 《这游戏也太真实了》450w | 废土+第四天灾+硬核种田 | 现象级 | 我们有**GM视角**+**莲花式地图结构** |
| 《十日终焉》 | 规则怪谈+无限流+高智博弈 | 番茄三榜榜首 | 我们有**玩家群像沙雕线**对冲严肃性 |
| 《地下城玩家》150w | 恶魔领主+压榨玩家+沙雕 | 中后期崩盘 | 我们有**因果链系统**防止剧情崩盘 |

**差异化优势**：莲花式地图（空间层次感）+ 千层饼（历史深度）+ GM视角（独特爽感）+ 玩家5种类型（群像丰满）

### 3.2 强化建议

#### A. 千层饼揭秘触发系统

当前问题：truth_layer 只在 midpoint 时通过 `advance_truth_layer()` 从1→2。6层揭秘没有自动触发机制。

**建议**：建立 truth revelation 触发矩阵：

```python
TRUTH_TRIGGERS = {
    1: {'condition': 'chapter >= 1', 'event': '归墟是源界废墟'},
    2: {'condition': 'first_fragment_recovered', 'event': '归墟是星图观测站'},
    3: {'condition': 'fragment_count >= 1 AND baiye_first_appearance', 
        'event': '万界是文明的实验场'},
    4: {'condition': 'fragment_count >= 3 AND player_count > 500', 
        'event': '祂们是入侵者'},
    5: {'condition': 'fragment_count >= 5 AND truth_layer >= 4', 
        'event': '第47次循环'},
    6: {'condition': 'fragment_count >= 8 AND truth_layer >= 5', 
        'event': '林朔的真实身份'}
}
```

#### B. "三番四震"节奏引擎（新增模块）

源自调研发现的高效网文节奏框架：

- **三番**：初番（打破常规）→ 深番（认知颠覆）→ 终番（降维打击）
- **四震**：怒与虐 → 惊与疑 → 爽与快 → 感与悟

可在 `causal_chapter.py` 中为每个节拍自动注入对应的"震"情绪节点。

#### C. 跨界混搭生成器（新增模块）

2026年网文最大趋势：**母题 + 嫁接元素 = 新爆款**。

为每个花瓣世界预设嫁接公式：
- 武侠·苍云之殇 × 民俗玄学 = 中式克苏鲁武侠
- 末日废土 × 职场管理学 = 带KPI的末世求生
- 赛博都市 × 非遗传承 = 数据化的传统技艺
- 低魔中世纪 × 经济学 = 通货膨胀导致的魔法衰退

### 6.1 当前黑名单（已实现 ✓）

```
不禁、忍不住、一股、涌上心头、不由自主地、下意识地、

```

### 6.2 新增20个AI高频词

基于调研中《宇宙巨校闪级生》原文特征的反思——机器感源于：
```
「只见」「但见」「说时迟那时快」「电光火石之间」
「心中暗道」「不由」「不由得」「顿时」「瞬间」
「缓缓」「淡淡」「微微」「轻轻」「深吸一口气」
「目光一凝」「眼神一凛」「面色一变」「浑身一震」
```

### 6.3 "人味注入"规则

新增7条authentic-voice规则（调研发现的真人写作特征）：
1. **不完整**：对话中被打断、句子不说完
2. **重复**：关键情绪词的重复强调（"他等得太久了。太久了。"）
3. **跑题**：人物对话中突然想到无关的事
4. **延迟**：不立刻回答问题，先沉默/做其他事
5. **错误**：角色说错话然后纠正自己
6. **物理性**：角色有生理需求（渴、饿、累、酸）
7. **当下**：记忆片段化跳跃，不无端精确回忆
